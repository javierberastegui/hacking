# Checklist defensiva de revisión del router WiFi propio

Usa esta lista solo sobre tu propio router o sobre equipos para los que tengas autorización. No sirve para analizar redes ajenas ni para comprobar vulnerabilidades.

## Antes de empezar

- [ ] Entrar únicamente por el canal oficial del router, app del operador o URL indicada por el fabricante/ISP.
- [ ] Tener a mano contrato, app oficial o teléfono de soporte del operador.
- [ ] Evitar escribir contraseñas completas en esta plantilla.
- [ ] Hacer la revisión desde un dispositivo propio y actualizado.
- [ ] Si la alerta viene de un SMS, email o llamada, no usar enlaces ni teléfonos incluidos ahí; verificar por canales independientes.

## Configuración básica

- [ ] Cambiar la contraseña de administración si es débil, antigua o compartida.
- [ ] Confirmar que la clave WiFi es larga, única y no reutilizada en otros servicios.
- [ ] Revisar que la red usa WPA2 o WPA3 si el equipo lo permite.
- [ ] Desactivar WPS si no se usa.
- [ ] Desactivar administración remota si no la necesitas.
- [ ] Revisar si hay firmware o actualización pendiente desde el canal oficial.
- [ ] Revisar DNS configurado y anotar si coincide con el operador o con un proveedor elegido conscientemente.

## Dispositivos y red de invitados

- [ ] Revisar la lista de dispositivos conectados desde el panel oficial, sin usar escáneres externos.
- [ ] Identificar dispositivos propios por nombre conocido cuando sea posible.
- [ ] Si aparece algo desconocido, cambiar clave WiFi y reiniciar conexión de dispositivos propios de forma ordenada.
- [ ] Activar o revisar red de invitados para visitas o dispositivos menos confiables si el router lo permite.
- [ ] Desconectar dispositivos antiguos que ya no uses si el panel ofrece esa opción.

## Cuentas críticas relacionadas

- [ ] Revisar correo principal, cuenta del operador, nube y gestor de contraseñas.
- [ ] Activar 2FA/passkeys en cuentas importantes cuando esté disponible.
- [ ] Cerrar sesiones desconocidas desde las opciones oficiales de cada cuenta.
- [ ] No reutilizar la clave del WiFi como contraseña de correo, banco, nube o panel del operador.

## Documentación sin secretos

- [ ] Anotar fecha de revisión.
- [ ] Anotar motivo de la revisión: aviso del operador, comportamiento extraño, dispositivo desconocido, cambio no reconocido, mantenimiento rutinario.
- [ ] Anotar cambios realizados sin escribir contraseñas completas.
- [ ] Guardar referencia de actualización de firmware si el panel muestra versión o fecha.
- [ ] Programar una revisión futura si hubo cambios importantes.

## Cuándo pedir ayuda

- [ ] Contactar con el ISP si no reconoces cambios de firmware, DNS, administración remota o configuración WAN.
- [ ] Contactar con el banco/proveedor afectado si introdujiste credenciales o datos de pago por un enlace sospechoso.
- [ ] Pedir ayuda profesional si hay señales repetidas, accesos no reconocidos en cuentas críticas o equipos comprometidos.

## Límites seguros

Esta checklist no incluye escaneo de redes, captura de tráfico, explotación, cracking WiFi, pruebas de contraseñas ni acciones sobre dispositivos de terceros.
