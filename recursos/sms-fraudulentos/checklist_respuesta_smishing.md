# Checklist segura de respuesta ante SMS fraudulentos (smishing)

Recurso defensivo para el artículo: https://javierberastegui.es/como-detectar-sms-fraudulentos

Este documento ayuda a actuar con calma ante un SMS sospechoso. No incluye análisis técnico de enlaces, llamadas externas, automatización ni instrucciones ofensivas.

## 1. Corta la interacción

- [ ] No pulsar enlaces del mensaje.
- [ ] No responder al SMS.
- [ ] No llamar a números incluidos en el propio SMS.
- [ ] No instalar aplicaciones sugeridas por el mensaje.
- [ ] No introducir contraseñas, códigos SMS/OTP, datos bancarios ni datos personales.
- [ ] Si ya se abrió el enlace, cerrar la página y no continuar navegando desde ahí.

## 2. Documenta lo básico sin exponerte más

Registra solo información que ya esté visible o que puedas obtener sin abrir enlaces:

- [ ] Fecha y hora de recepción.
- [ ] Remitente visible: número, alias o nombre mostrado.
- [ ] Entidad que dice representar.
- [ ] Resumen del mensaje.
- [ ] Dominio o enlace visible como texto, sin abrirlo.
- [ ] Acción que pedía el SMS: pagar, confirmar entrega, iniciar sesión, desbloquear cuenta, actualizar datos, llamar, instalar app, etc.
- [ ] Si hiciste clic o no.
- [ ] Si introdujiste datos o no.
- [ ] Si autorizaste algún pago, transferencia, Bizum, alta de tarjeta o cambio de contraseña.
- [ ] Acciones ya realizadas.
- [ ] Capturas de pantalla si puedes hacerlas sin volver a abrir enlaces ni mostrar datos sensibles innecesarios.

## 3. Decide según tu exposición

### Solo recibiste el SMS y no hiciste clic

- [ ] No responder.
- [ ] No abrir enlaces.
- [ ] Bloquear o marcar como spam si tu móvil lo permite.
- [ ] Verificar cualquier aviso desde la app oficial, web oficial escrita manualmente o teléfono oficial.

### Hiciste clic, pero no introdujiste datos

- [ ] Cerrar la página.
- [ ] No descargar ni instalar nada.
- [ ] No conceder permisos si el navegador o el sistema los solicita.
- [ ] Revisar si se descargó algún archivo y no abrirlo si no confías en su origen.
- [ ] Verificar la supuesta incidencia por canales oficiales.

### Introdujiste contraseña o datos de acceso

- [ ] Cambiar la contraseña desde la web o app oficial.
- [ ] Cambiar esa contraseña en otros servicios si estaba reutilizada.
- [ ] Cerrar sesiones abiertas si el servicio lo permite.
- [ ] Activar o revisar 2FA, passkeys o llaves de seguridad FIDO2 si están disponibles.
- [ ] Revisar correo, teléfono, métodos de recuperación y dispositivos vinculados.

### Introdujiste datos bancarios o de tarjeta

- [ ] Contactar cuanto antes con el banco por app oficial, teléfono del reverso de la tarjeta o canales oficiales.
- [ ] Explicar qué datos introdujiste y si autorizaste algún cargo.
- [ ] Solicitar bloqueo o sustitución de tarjeta si el banco lo recomienda.
- [ ] Revisar movimientos recientes y configurar avisos si están disponibles.
- [ ] Preguntar por el procedimiento de reclamación si hubo cargos no reconocidos.

### Compartiste un código SMS, OTP o clave de firma

- [ ] Contactar de inmediato con la entidad afectada por canales oficiales.
- [ ] Indicar que compartiste un código de verificación o autorización.
- [ ] Revisar operaciones, cambios de contraseña, altas de dispositivos o modificaciones de datos.
- [ ] Cambiar credenciales desde sitio o app oficial.

### Realizaste un pago o transferencia

- [ ] Contactar con el banco o proveedor de pago por canales oficiales lo antes posible.
- [ ] Aportar fecha, hora, importe, beneficiario si aparece y capturas disponibles.
- [ ] Preguntar si la operación puede bloquearse, revertirse o reclamarse.
- [ ] Conservar toda la evidencia.
- [ ] Valorar presentar denuncia si hay pérdida económica, suplantación o uso indebido de datos.

## 4. Qué no hacer

- No responder al SMS aunque parezca que puedes cancelar la operación.
- No reenviarlo sin contexto a familiares o contactos.
- No llamar a números incluidos en el mensaje.
- No instalar apps recomendadas por el SMS.
- No compartir códigos SMS, OTP, claves de firma ni PIN.
- No introducir datos para comprobar si la página es real.
- No pagar tasas, envíos o desbloqueos desde el enlace recibido.
- No confiar solo en que el SMS aparezca dentro de un hilo con mensajes legítimos anteriores.
